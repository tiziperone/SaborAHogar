# Sabor a Hogar | Pastas Caseras

Página web para encargar pastas caseras hechas a mano: ravioles, sorrentinos y fideos. Los pedidos se hacen directamente por WhatsApp, sin necesidad de crear cuenta ni completar formularios complicados.

## ¿Qué ofrece?

- **Ravioles** de jamón y queso, y de ricota y espinaca.
- **Sorrentinos** de jamón y queso, y de ricota y espinaca.
- **Fideos** de huevo y de espinaca, en 500 g o 1 kg.

Los precios se eligen según la presentación: media docena o docena para las pastas rellenas, y medio kilo o kilo para los fideos.

## Cómo hacer un pedido

1. **Elegí** la pasta, la presentación y la cantidad.
2. **Sumala al carrito** para seguir comprando, o tocá **Comprar** para pedir solo esa pasta.
3. **Completá** tu nombre, la forma de entrega (retiro o envío en Florencia, Santa Fe), la forma de pago y alguna aclaración.
4. **Enviá el pedido**: se abre WhatsApp con todo el detalle listo para mandar.

Una vez enviado, el carrito se vacía solo.

## Características

- Diseño cálido inspirado en la cocina casera.
- Funciona bien en celular y computadora.
- Carrito que se mantiene aunque cierres la página.
- Se puede instalar en la pantalla de inicio del celular, como una app.
- Botón para volver arriba y acceso rápido al carrito en todo momento.
