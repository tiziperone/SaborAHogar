# Sabor a Hogar | Pastas Caseras 🍝

Página web para encargar pastas caseras hechas a mano: raviolones, sorrentinos y fideos. Los pedidos se hacen directamente por WhatsApp, sin necesidad de crear cuenta ni completar formularios complicados.

## ¿Qué ofrece?

- **Raviolones** de jamón y queso, y de ricota y verduras.
- **Sorrentinos** de jamón y queso, y de ricota y verduras.
- **Fideos** de huevo y de espinaca, en 500g o 1kg.

Los precios se ajustan según la elección: media docena o docena para las pastas rellenas, y medio kilo o kilo para los fideos.

## Cómo hacer un pedido

1. **Elegí** la pasta y la cantidad.
2. **Sumala al carrito** para seguir comprando, o tocá **Comprar** para pedir solo esa pasta.
3. **Completá** tu nombre, la forma de entrega (retiro o envío en Florencia, Santa Fe), la forma de pago y alguna aclaración (si es necesaria).
4. **Enviá el pedido**: se abre WhatsApp con todo el detalle listo para mandar.

Una vez enviado, el carrito se vacía solo.

## Características

- Diseño cálido inspirado en la cocina casera.
- Funcional en celular y computadora.
- Carrito que se mantiene aunque cierres la página.
- Se puede instalar en la pantalla de inicio del celular, como una app.
- Botón para volver arriba y acceso rápido al carrito en todo momento.
- **WhatsApp:** desde el botón "Consultanos por WhatsApp" de la página.
- **Instagram:** [@saborahogar.pastas](https://www.instagram.com/saborahogar.pastas)
